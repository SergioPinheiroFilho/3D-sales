# 3D Sales Japan

Projeto de venda de produtos impressos em 3D no Japão.

## Objetivos
- Criar uma fonte de renda extra.
- Desenvolver produtos originais com impressão 3D FDM.
- Pesquisar o mercado japonês.
- Implementar uma equipe semiautônoma de agentes de IA.

## Nichos prioritários
- Organizadores de jogos de tabuleiro.
- Suportes para action figures.
- Acessórios para modelismo.

## Primeiro agente
Market Research JP — Pesquisa de mercado japonês.
